# 企业网站无障碍整改项目管理平台

面向审核员、开发人员、复测员和跨团队负责人的无障碍整改工作台。支持 WCAG 问题录入、同根因合并、复测流转、版本差异、批量分配、草稿恢复和整改报告导出。

## 技术栈

React + Ant Design + Zustand + React Router + TanStack Query + Axios + MSW + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:62047`。

## 核心工作流

- 从站点、WCAG 条款、影响范围和证据链接建立问题台账。
- 将同根因问题合并为整改项，并批量指派团队、优先级和截止日期。
- 开发提交修复说明与复测环境，复测员逐项通过、退回或标记不适用。
- 保存常用筛选，比较版本差异，恢复未提交编辑并导出整改报告。

## 断网结果合并（离线同步）

审核员现场断网时可在多页采集结果，恢复网络后在「断网合并」页按问题编号并入：

- **按编号并入**：两页结果逐条按问题编号落入台账；支持导入断网结果 JSON。
- **两份待确认、不覆盖**：同一问题两页都新增复测时，两份记录都保留为「待确认」，由审核员逐条采纳或驳回，绝不覆盖已有记录。
- **证据更新即失效**：证据更新后旧的「已通过」立即失效、状态回到「待复测」重算；报告草稿与台账标出失效来源（旧/新证据、来源页、旧结论编号）。采纳新的「通过」结论或在线复测通过后解除。
- **断点恢复**：导入中断时保留已落地改动，从「最后确认项」之后继续；前序内容不重复提交。
- **幂等**：以 `submissionId` 去重，重复提交只认第一次（服务端幂等账本 + 本地校验）。
- **统计口径**：清单、台账、总览、侧边栏与 CSV 导出统一显示「待确认数量」与「阻塞项」（待确认或失效待重算）。

核心纯逻辑位于 `src/api/merge.ts`，MSW 服务端在 `src/api/browser.ts` 做幂等与一次性断连模拟；`scripts/merge.test.ts` 为可运行的断言脚本（`npx esbuild` 打包后 `node` 执行）。
